## 1. Forbidden, absolutely

- No `rm` outside `~/lanes/tl25/` (kasumi and nomad-1); no deletion in any
  tree this lane did not create; no `git add -A`; nothing under `~/.claude`.
- Nothing in another org's repository.

  under `~/lanes/tl25/` with `CARGO_BUILD_JOBS=4` and `CARGO_INCREMENTAL=0`,
  one target dir, pruned when the evidence is written. Lanes install no host
  tool.
- No merge, no tag, no issue filed or closed; the branch is asserted before
  every commit; no attribution trailers on any commit or PR.
- **The pin is the release, by digest, each digest read twice**: wolf 0.2.32
  is `v0.2.32` at `72de141f`, lupin 0.1.54 is `v0.1.54` at `0e536e8`, the
  bundled std wolf-std `d37c911`. Never wolf-lang's trunk, a clone's build,
  Homebrew or `~/.local/bin`.

  client gains a list of prelude functions, the seven new ones included.
- **Strict evidence** (wolf-lang#571): server gates with `--require-server`;
  `cargo test` with `--nocapture` and the SKIP lines counted; the spawning
  suites also under `taskset -c 0-3`.
- A count is compared as a key-set diff both ways, never as a number
  (wolf-lang#177): anchors over `.anchors`, prelude names over `.names`,
  transcripts by `dir`.
- No "seen red" without a run id, sha, path or captured log in the same
  paragraph. Kill only pids this lane started; kasumi jobs `setsid` with a
  pid file; waits print at least every five minutes.
